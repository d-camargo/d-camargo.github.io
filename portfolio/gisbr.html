GisBR

Plugin QGIS que traz os dados espaciais oficiais do Brasil direto para a Caixa de Ferramentas de Processamento.

O Problema

Quem trabalha com análise espacial no Brasil conhece a rotina: para montar um mapa municipal, é preciso navegar pelo FTP do IBGE, localizar a malha do ano correto, baixar o arquivo compactado, extrair e só então carregar no QGIS. O pacote geobr, do IPEA, resolveu essa etapa de forma elegante para quem programa em R ou Python — uma função retorna a camada pronta —, mas deixou de fora a maior parte dos profissionais de geoprocessamento, que trabalham direto no QGIS e não escrevem código.

O mesmo vale para o diagnóstico de um município na elaboração de um Plano Diretor: reunir as bases oficiais de transporte, saneamento, demografia e meio ambiente significa consultar manualmente dezenas de servidores WFS, ArcGIS REST e portais de download diferentes, cada um com seu próprio formato e sistema de referência.

A Solução — Evolução do Projeto

v0.2.0 — Lançamento experimental

Aprovação no repositório oficial de complementos do QGIS. Cada geografia do geobr vira um algoritmo de Processing: 55 ao todo, cobrindo divisão administrativa, censo, áreas urbanas e metropolitanas, meio ambiente e temas setoriais como saúde e educação, além do algoritmo join_censo, que cruza setores censitários com as tabelas demográficas do censobr. Decisão de projeto: zero dependências externas, só a API nativa do QGIS/Qt e a biblioteca padrão do Python.

v0.3.2 — Malha viária do OSM

Download da rede viária de qualquer município direto do OpenStreetMap via API Overpass, estruturada como links e nós com topologia mínima — a mesma lógica do osm2gmns, do professor Xuesong Zhou (Arizona State University), aplicada dentro do QGIS. Corrigido também um timeout que nunca era aplicado às consultas Overpass. Primeira versão publicada sem o rótulo "experimental".

v0.4.0 / v0.4.1 — Compatibilidade QGIS 4.x

Declaração explícita de suporte ao QGIS 4.x e correção de um bug de escopo de enum no PyQt6 que derrubava o catálogo de municípios e a checagem de erros do Overpass.

v0.4.3 — Certificados SSL consolidados

O suporte a certificados SSL, até então restrito ao downloader do IPEA, passou para um módulo único (core/ssl_support.py) e se estendeu a todos os conectores do plugin — WFS, ArcGIS REST, Overpass e o basemap de satélite —, resolvendo falhas de cadeia de certificado em instalações novas de Windows/OSGeo4W ao consultar fontes como SICAR, ANA/SNIRH, INDE, SGB e IBAMA.

Funcionalidades Principais

55 algoritmos de Processing: cada geografia oficial (país, estados, municípios, setores censitários, biomas, unidades de conservação, terras indígenas, favelas, locais de votação e mais) vira um algoritmo com parâmetros de ano, filtro por UF ou código IBGE e opção de geometria simplificada.

Malha viária do OpenStreetMap: download das vias de qualquer município via Overpass, montadas como uma rede de links e nós pronta para modelagem de transportes, em SIRGAS 2000 (EPSG:4674).

Cache local com espelho no GitHub: downloads ficam em cache em disco; se o servidor do IPEA estiver fora do ar, o plugin busca os mesmos arquivos em um espelho no GitHub, sem interromper o fluxo de trabalho.

Certificados SSL embarcados: reconhece as cadeias de confiança de IPEA, SICAR, ANA/SNIRH, INDE, SGB, IBAMA, Overpass e o basemap de satélite, resolvendo falhas de instalações novas de Windows sem relaxar nenhuma verificação de segurança.

Zero dependências externas: funciona apenas com a API nativa do QGIS/Qt e a biblioteca padrão do Python — sem geopandas, pandas ou requests, o que evita conflitos com outros plugins e barreiras de instalação para usuários menos técnicos.

Stack Tecnológica

Python PyQGIS QGIS Processing Framework Overpass API GeoPackage / SQLite Parquet / GDAL

Impacto

O GisBR elimina a etapa manual de busca, download e conversão de dados oficiais para quem trabalha em QGIS, cobrindo dezenas de geografias administrativas, censitárias, ambientais e setoriais, além da malha viária do OpenStreetMap — tudo sem exigir conhecimento de programação. O projeto está evoluindo para um sistema de diagnóstico municipal automatizado, voltado à elaboração e revisão de Planos Diretores, que reúne as bases oficiais de um município já recortadas pelo seu polígono em um único GeoPackage.
