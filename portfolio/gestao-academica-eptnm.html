Gestão Acadêmica EPTNM

Automatizando o acompanhamento de turmas dos cursos técnicos do CEFET-MG com Python e Streamlit.

O Problema

O SIGAA — sistema acadêmico institucional do CEFET-MG — não emite relatórios de gestão consolidados para turmas dos cursos técnicos de nível médio (EPTNM). Para um coordenador acompanhar o desempenho dos alunos, era necessário baixar o mapa de turma — que contém todas as disciplinas — e cruzar os dados manualmente, um processo repetitivo e sujeito a erros que consumia horas a cada bimestre.

O cenário é ainda mais complexo nos cursos de Trânsito e Estradas. A partir do 2º ano, as disciplinas técnicas se diferenciam entre os dois cursos — embora as disciplinas de Ensino Médio permaneçam as mesmas. Isso significa que, para os alunos do 2º e 3º anos, existem planilhas XLS distintas para as disciplinas técnicas de cada curso, enquanto o núcleo de Ensino Médio segue na mesma planilha compartilhada.

A Solução — Evolução do Projeto

2022

Primeira versão desenvolvida em Google Colab. O script já lia o arquivo MapaTurma.xls exportado do SIGAA e gerava os relatórios de forma automatizada, eliminando o trabalho manual de compilação de dados.

2025 — Reativação

Ao retornar à coordenação do curso, o código foi reativado e expandido: passou a gerar automaticamente o relatório em PDF com layout profissional (gráficos, boxplots, sumário dinâmico) e incorporou a API da OpenAI como funcionalidade opcional, gerando parágrafos analíticos sobre os dados processados.

2026 — Generalização e Streamlit

Com o apoio de Inteligência Artificial para acelerar o desenvolvimento, o código foi generalizado para atender qualquer curso da EPTNM, não apenas o de Trânsito. Em seguida, os scripts foram empacotados em uma aplicação web com Streamlit, permitindo que qualquer coordenador envie sua planilha e receba o relatório PDF direto no e-mail institucional, sem instalar nada.

Funcionalidades Principais

Processamento inteligente de mapas de turma: O sistema extrai automaticamente o nome do curso, a turma e o bimestre a partir do cabeçalho da planilha XLS exportada do SIGAA. Caso a planilha contenha dados misturados de dois bimestres, a execução é abortada com aviso ao usuário para garantir precisão estatística.

Régua de aprovação dinâmica: O CEFET-MG distribui pontos de forma variável — 1º e 3º bimestres valem 20 pontos; 2º e 4º valem 30. O sistema identifica o bimestre e ajusta automaticamente o limiar de aprovação (60%), tornando precisas as taxas calculadas sem nenhuma configuração manual.

Análise estatística de faltas: A frequência é analisada por métricas estatísticas (média, mediana, P90, desvio padrão) em vez de um cálculo fixo de carga horária. Isso permite identificar anomalias — alunos acima do P90 ou além de média + 2σ — e produzir um ranking dos dez maiores faltosos do bimestre.

Relatório PDF profissional: Gerado com ReportLab, o documento inclui sumário dinâmico (TOC), histograma de faltas, boxplots por disciplina, gráficos de desempenho, listagem de alunos e disciplinas críticas, e um parágrafo analítico opcional gerado por IA.

Caso especial Trânsito + Estradas (2º e 3º anos): A partir do 2º ano, cada curso possui suas próprias disciplinas técnicas em planilhas XLS separadas, mas o núcleo de Ensino Médio permanece numa planilha compartilhada. Ao ativar esse modo, o coordenador sobe as duas planilhas de técnicas; o sistema extrai as notas do Ensino Médio da planilha de Estradas, incorpora nos dados de Trânsito, e então gera dois PDFs distintos — um para cada curso — enviando-os juntos no mesmo e-mail.

Privacidade por design: O acesso de envio é restrito ao domínio @cefetmg.br. Planilhas e PDFs são processados exclusivamente em memória RAM (BytesIO) — nenhum dado de aluno é salvo em disco ou disponibilizado para download no site.

Stack Tecnológica

Python Streamlit Pandas ReportLab smtplib OpenAI API

Impacto

O sistema substituiu um processo inteiramente manual — que antes exigia horas de compilação de dados a cada bimestre — por uma interface web acessível e centralizada. Hoje, qualquer coordenador da EPTNM do CEFET-MG pode, em minutos, obter um relatório gerencial completo no seu e-mail institucional, com dados e gráficos prontos para embasar intervenções pedagógicas mais ágeis e precisas.
